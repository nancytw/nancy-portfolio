Email Cyber Guardian Agent Lab

Automated Email Security AI Analysis Workflow using Azure Logic Apps and Azure OpenAI.

🎯 About This Lab

The goal of this lab is to build an automated Email Security AI analysis workflow in a test tenant and Azure lab environment. When a test email arrives, Azure Logic Apps triggers an Azure OpenAI deployment for risk analysis (phishing, credential harvesting, malware, etc.) and automatically sends the results back to the mailbox.

Note: This lab is for learning and testing purposes only. It does not replace Microsoft Defender for Office 365 and should not be used directly in production.

📊 Architecture Options & Cost Comparison

Option Architecture Cost Pros & Cons
Option 1 Logic App + MDO + Sentinel $$$ Enterprise Grade, high cost.
Option 2 Logic App + Free Threat Intel API $ Low cost, limited accuracy.
Option 3 Logic App + Azure OpenAI + Outlook $$ Balanced cost & capability, low-code, high flexibility.

💡 Architecture Choice & Roadmap

My current lab is based on Option 3 (Azure Logic Apps + Azure OpenAI + Outlook). I chose it because it provides a good balance between cost, low-code implementation, and real-world enterprise security automation. My future roadmap includes threat intelligence enrichment, Sentinel integration, and eventually evolving the solution into a Copilot Studio AI Agent with RAG capabilities.

⚙️ Tech Stack & Architecture

  • Azure Logic Apps: Used to build the overall automation workflow.
  • Azure OpenAI Connector: Used by Logic App to call the Azure OpenAI model.
  • Azure OpenAI Resource & Deployment: Used to host the GPT deployment and provide the API key.
  • Office 365 Outlook Connector: Used to monitor mailbox and send analysis results.
  • Test Tenant Mailboxes: Used for sending/receiving test and analysis emails.

🧠 AI Analysis Engine (Powered by GPT-5)

Model Selected: Azure OpenAI GPT-5

The system automatically sends emails to the GPT-5 model for preliminary risk analysis, scanning for the following threat indicators:

  • Phishing
  • Credential harvesting
  • Suspicious URLs
  • Malware indicators
  • Business Email Compromise (BEC)
  • Impersonation & Social engineering

🚀 Key Features

  • Auto Trigger: Automatically initiates processing via Logic Apps upon receiving emails.
  • AI Risk Review: Instantly filters, scans content, and identifies potential risks or anomalies.
  • High Maintainability: Modular design allowing easy expansion of protection rules.

🔄 Automation Flow

Test email arrives → Logic App triggered → Sends content to Azure OpenAI (GPT-5) → AI analyzes risk → Formats result → Outlook Connector sends analysis email to recipient.

📌 Important Notes

  • The API key is securely stored in the Azure OpenAI Connector connection.
  • HTTP action can also be used to call Azure OpenAI REST API directly (Azure Key Vault can be integrated for secret management).
  • Recommended to use test tenant mailboxes rather than personal Outlook.com to avoid risk controls and sending limits.

🛠️ Full Implementation Steps

  1. Create the Azure Logic App & Outlook connection.
  2. Configure Azure OpenAI (GPT-5).
  3. Build the Prompt Engineering logic.
  4. Test and Validate with malicious/benign emails.

🔮 Future Improvements
