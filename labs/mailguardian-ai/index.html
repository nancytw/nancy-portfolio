自動化郵件資安防護網

基於 Azure Logic Apps 與 Azure OpenAI 的低程式碼企業級安全自動化解決方案

👨‍💻 Author: Nancy Wei
Cloud Automation AI Integration Security Analysis Low-Code Development

📌 專案目標 (Lab Objective)

建立一個全自動化的 Email 資安分析工作流。當測試租戶信箱收到郵件時，自動攔截並交由 AI 進行深度風險評估，最後將分析報告發送給指定的安全人員。

⚠️ 聲明：本實驗室僅供學習與測試使用，若要在正式生產環境使用，需進行隱私與合規性審查。

⚖️ 架構評估與決策 (Architecture Decision)

在開發前，我針對「成本、擴充性與維護難易度」評估了四種 Azure 解決方案，以找出最適合的平衡點：

[方案 1] Power Automate + Azure OpenAI

  • 💰 成本：最低 (Lowest)
  • 📈 擴充性：低-中 (Low-Mid)

📝 易於建置維護，適合簡單自動化，但缺乏企業級規模整合彈性。

[方案 2] Azure Functions + Azure OpenAI

  • 💰 成本：低 (Low)
  • 📈 擴充性：高 (High)

📝 高度客製化且成本效益高，但需要較多程式編寫與後續程式碼維護。

🏆 最終選擇 (Current Solution)

⭐ [方案 3] Azure Logic Apps + Azure OpenAI

  • 💰 成本：中等 (Moderate)
  • 📈 擴充性：高 (High)

📝 提供成本、低程式碼開發與企業級整合之間的絕佳平衡。特別適合雲端原生的安全自動化工作流。

🚀 未來藍圖 (Future Roadmap)

[方案 4] Copilot Studio + RAG + Logic Apps

  • 💰 成本：最高 (Highest)
  • 📈 擴充性：極高 (Very High)

📝 支援進階 AI 代理與企業知識庫整合，是未來 Security Copilot 場景的終極目標。
