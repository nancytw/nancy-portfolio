Email Cyber Guardian Agent Lab 郵件資安防護與 AI 分析實作

使用 Azure Logic Apps 與 Azure OpenAI 實現自動化郵件資安 AI 分析工作流程。

🎯 1. Lab Objective (實驗目標與目的)

本實驗旨在於測試租戶與 Azure 實驗環境中建立自動化郵件資安 AI 分析工作流程。當測試信箱收到符合條件的信件時，Azure Logic Apps 會自動觸發工作流程，將主旨與內文送交 Azure OpenAI 部署進行風險分析（如網路釣魚、憑證竊取、惡意軟體、社交工程等），並自動將 AI 產生的分析結果回傳至指定信箱。

⚠️ 注意：本實驗僅供學習與測試使用，不替代 Microsoft Defender for Office 365，請勿直接用於正式環境。

⚙️ 2. Services and Components Used (使用的技術與服務)

  • Azure Logic Apps： 用於建構整體自動化工作流程。
  • Azure OpenAI Connector： Logic App 用來呼叫 Azure OpenAI 模型。
  • Azure OpenAI Resource & Deployment： 用於託管 GPT 部署並提供 API 金鑰。
  • Office 365 Outlook Connector： 用來監控測試信箱並發送 AI 分析結果郵件。
  • Test Tenant Mailboxes： 用於發送測試郵件及接收分析結果。

🔄 3. Automation Flow (自動化流程)

測試郵件抵達信箱 ➔ Logic App 自動觸發 ➔ 傳送郵件內容至 Azure OpenAI ➔ AI 分析資安風險 ➔ 格式化分析結果 ➔ 透過 Outlook Connector 發送分析郵件給使用者。

📌 4. Important Notes (重要注意事項)

  • API 金鑰安全儲存在 Azure OpenAI Connector 連線設定中。
  • 可使用 HTTP 動作直接呼叫 REST API（亦可整合 Azure Key Vault 進行金鑰管理）。
  • 建議使用測試租戶信箱，不建議使用個人 Outlook.com 信箱以免觸發流量限制。
